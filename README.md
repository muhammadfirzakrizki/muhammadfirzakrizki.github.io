# Muhammad Firzak Rizki - Full-Stack Software Engineer

Website portofolio pribadi yang merepresentasikan keahlian sebagai **Full-Stack Software Engineer**. Portofolio ini menampilkan rekam jejak dalam membangun "seluruh ekosistem" perangkat lunak—mulai dari arsitektur backend dan logika bisnis yang kompleks (seperti Sistem Enterprise dan Manajemen Database) hingga antarmuka *client* yang intuitif dan responsif di platform Web maupun Mobile.

## 🚀 Fitur Utama
- **Hybrid Portfolio**: Menampilkan proyek sistem web kompleks (Sistem Enterprise & API) sekaligus aplikasi mobile (Flutter).
- **Dukungan Multi-Bahasa (i18n)**: Beralih instan antara Bahasa Indonesia (ID) dan Inggris (EN) menggunakan Alpine.js & `translations.json`.
- **Desain Modern & Responsif**: Menggunakan Tailwind CSS + DaisyUI dengan dukungan Mode Gelap/Terang yang dinamis.
- **Interaktivitas Halus**: Animasi scroll yang elegan ditenagai oleh AOS (Animate On Scroll).
- **Performa Ringan**: Arsitektur tanpa proses *build*, menggunakan CDN untuk library utama sehingga sangat cepat saat dimuat.

## 🛠️ Core Tech Stack & Arsenal

### 🌐 Web Ecosystem (Frontend & Backend)
- **Frameworks**: Next.js, React.js, Laravel, CodeIgniter, Vue.js
- **Languages**: TypeScript, JavaScript (ES6+), PHP
- **Styling & UI**: Tailwind CSS, DaisyUI, Alpine.js
- **Architecture & API**: RESTful API, AJAX, Server-Side Rendering (SSR)

### 📱 Mobile Engineering
- **Frameworks**: Flutter, React Native
- **Languages**: Dart, TypeScript
- **State Management**: BLoC, Riverpod

### 💾 Data & Infrastructure
- **Databases**: MySQL, SQLite
- **BaaS / Backend**: Firebase

## 📂 Struktur Proyek Ini
- `index.html` — Halaman utama dan logika Alpine.js.

## 🖥️ Cara Menjalankan
1. *Clone* repositori ini.
2. Buka `index.html` langsung di browser, atau gunakan **Live Server** di VS Code.
3. Pastikan koneksi internet aktif untuk memuat library via CDN.
